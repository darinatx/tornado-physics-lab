# Tornado Sim

A physics-based tornado simulator: a tornado moves through a procedural city and destroys it
according to wind-engineering physics (Rankine-type vortex, dynamic pressure, EF-scale fragility).

- How we work: [CLAUDE.md](CLAUDE.md)
- Specs: [docs/specs](docs/specs)
- Roadmap: [docs/phases/ROADMAP.md](docs/phases/ROADMAP.md)

```bash
npm install
npm run dev       # run the app
npm run verify    # typecheck + tests + spec traceability
```
